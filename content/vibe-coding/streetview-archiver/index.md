Und noch ein von OX Alpha generiertes Spielzeug. Passend zu dem Blogbeitrag '[Digitale "Lost Places"](https://christianmahnke.de/post/digital-lost-places/)' habe ich Ox Alpha gebeten einen einfachen Downloader für Fotos von Google Maps zu laden, sowohl die "normalen" Straßenansichten als auch die interessanteren Innenansichten.

Dazu gibt es auch einen Viewer in dem die Sphären betrachtet werden können. Wie immer ist das Ganze auf [Github verfügbar](https://github.com/cmahnke/streetview-archiver).

Der Bereich aus dem Beitrag kann einfach mit dem `demo.sh` Script heruntergeladen werden:

```
git clone https://github.com/cmahnke/streetview-archiver.git
cd streetview-archiver
./demo.sh
```

Wie beim letzten Beitrag wird auch für dieses Tool keine Garantie übernommen.
